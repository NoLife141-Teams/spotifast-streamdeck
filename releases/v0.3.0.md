# Spotifast Stream Deck 0.3.0 — Beta

## English

Version 0.3.0 brings the eight reviewed and merged feature lots from PRs #18–#25
to Stream Deck while preserving existing action identifiers, saved settings and
default appearance.

### Playback and appearance

- **Set volume:** assign a 0–100% volume target to a key. Relative volume, mute
  and absolute volume retain their order. Multi Actions preserve every command
  in input order without combining macro steps.
- **Seek and restart:** move backward or forward by a configurable number of
  seconds (10 by default), or restart at 0:00. Bounds, stale state and
  key/profile/configuration changes are checked before commands run.
- **Local diagnostics:** preview and copy allowlisted connection information and
  useful error categories. Explicit inspector connection checks work even when
  no plugin key is visible. Diagnostics exclude account details, personal paths,
  track metadata and device identifiers; nothing is sent automatically.
- **Named Spotify shortcuts:** optionally name each link key and distinguish
  playlist, album, track, artist and show links. Recognized syntax does not
  guarantee content availability or playback support for an account.
- **Appearance preview:** inspect cached artwork while editing settings.
  Optional elapsed-time and progress overlays share the existing bounded
  animation loop and add no CLI reads. Existing display defaults are unchanged.
- **Playback devices:** show the device reported as active, explicitly refresh
  the inventory and transfer only to the selected device ID. Missing selections
  never fall back to an arbitrary device.

### Performance and installer integrity

- Repeatable synthetic playback/renderer benchmarks and a read-only Windows
  process sampler cover CPU, memory, timing and display output. CPU measurements
  use a meaningful sample window; peak-memory values are reported correctly.
  Synthetic timings do not certify physical latency or whole-system usage.
- The actual packed installer is checked against the tested build, extracted
  and exercised with the real Elgato SDK. Checksums remain bound to the bytes
  inspected during verification and release staging.
- Publication waits for both Windows Node 20 and Node 22 checks. The canonical
  installer comes from the verified Node 20 lane and is published without
  rebuilding.

### Installation, validation and limits

Download **rocks.spotifast.streamdeck.streamDeckPlugin** from this release and
open it manually to install or update. Requires **Windows x64**, **Stream Deck
7.1+**, and Spotifast installed and signed in to Spotify. Existing Spotify account
requirements are unchanged. CLI compatibility was checked against Spotifast
**v0.13.3**.

The automated gates run **225 tests on each Windows runtime, Node 20 and 22**,
plus dependency audit, build, Elgato validation, packaging and verification of
**185 installer files** with an extracted-installer SDK smoke test.
**SHA256SUMS.txt** covers the installer, **LICENSE**, **RELEASE_NOTES.md** and
**package-verification.json**. The plugin remains free and MIT licensed.

This is a **beta release**. Fresh installation, upgrade from 0.2.7, playback on
physical hardware, sleep/wake, reconnects and **Stream Deck + controls are not
tested for this version**. No automatic installation or update is performed.
Upstream lacks atomic seek-by-track-ID, so an external track change between the
final read and write remains possible. Device inventories can remain cached
after refresh; CLI acceptance does not confirm a completed remote transfer.

## Français

La version 0.3.0 réunit les huit lots fonctionnels revus et fusionnés dans les
PR #18 à #25, en conservant les identifiants des actions, les réglages enregistrés
et l’affichage par défaut.

### Lecture et affichage

- **Définir le volume :** affecter un volume de 0 à 100 % à une touche. Le volume
  relatif, la sourdine et le volume absolu conservent leur ordre. Les multi-actions
  exécutent leurs commandes dans l’ordre de saisie, sans regrouper leurs étapes.
- **Avancer, reculer et recommencer :** déplacer la lecture d’un nombre de secondes
  réglable (10 par défaut), ou revenir à 0:00. Les bornes, les états obsolètes et
  les changements de touche, profil ou configuration sont contrôlés avant l’envoi.
- **Diagnostics locaux :** afficher puis copier des informations de connexion
  autorisées et des catégories d’erreurs utiles. Les tests de connexion depuis
  les réglages sont pris en compte même sans touche visible. Les diagnostics
  excluent comptes, chemins personnels, métadonnées musicales et identifiants
  d’appareil ; rien n’est envoyé automatiquement.
- **Raccourcis Spotify nommés :** nommer chaque touche et distinguer les liens de
  playlist, album, morceau, artiste et émission. Un format reconnu ne garantit
  ni la disponibilité du contenu ni sa lecture sur le compte.
- **Aperçu de l’apparence :** visualiser la pochette en cache depuis les réglages.
  Le temps écoulé et la progression facultatifs partagent la boucle d’animation
  bornée, sans lecture CLI supplémentaire. Les options par défaut sont conservées.
- **Appareils de lecture :** afficher l’appareil actif annoncé, actualiser
  explicitement la liste et transférer uniquement vers l’identifiant choisi.
  Un appareil manquant n’est jamais remplacé arbitrairement.

### Mesures et intégrité de l’installateur

- Des scénarios simulés reproductibles et un outil Windows de lecture des
  processus mesurent CPU, mémoire, délais et sorties d’affichage. La durée des
  mesures CPU et les pics mémoire ont été corrigés. Ces mesures ne certifient
  ni la latence physique ni la consommation globale du système.
- L’installateur empaqueté est comparé à la compilation testée, extrait puis
  exercé avec le véritable SDK Elgato. Les empreintes restent liées aux octets
  inspectés pendant la vérification et la préparation de publication.
- La publication attend les contrôles Windows Node 20 et Node 22. L’installateur
  officiel provient de la voie Node 20 vérifiée, sans nouvelle compilation.

### Installation, validation et limites

Télécharger **rocks.spotifast.streamdeck.streamDeckPlugin** depuis cette release,
puis l’ouvrir manuellement pour installer ou mettre à jour. Nécessite **Windows
x64**, **Stream Deck 7.1+** et Spotifast installé et connecté à Spotify. Les
exigences du compte Spotify restent inchangées. La compatibilité CLI a été
vérifiée avec Spotifast **v0.13.3**.

Les contrôles automatisés exécutent **225 tests sur chacun des runtimes Windows
Node 20 et 22**, ainsi que l’audit des dépendances, la compilation, la validation
Elgato, l’empaquetage et la vérification des **185 fichiers de l’installateur**,
avec un test SDK depuis l’archive extraite. **SHA256SUMS.txt** couvre
l’installateur, **LICENSE**, **RELEASE_NOTES.md** et **package-verification.json**.
Le plugin reste gratuit sous licence MIT.

Cette release est **bêta**. L’installation neuve, la mise à jour depuis 0.2.7, la
lecture sur matériel, la veille/reprise, les reconnexions et les **commandes
Stream Deck + ne sont pas testées pour cette version**. Aucune installation ou
mise à jour automatique n’est effectuée. L’API amont ne permet pas un déplacement
atomique lié au morceau : un changement externe entre lecture et écriture reste
possible. La liste des appareils peut rester en cache après actualisation ;
l’acceptation CLI ne confirme pas la réussite d’un transfert distant.
