# Spotifast Stream Deck 0.3.1 — Beta

## English

Stream Deck + dial rotation can now be configured per dial action:

- **Adjust volume** remains the default, including for existing dial setups.
- **Change tracks** maps clockwise ticks to Next and counter-clockwise ticks to
  Previous. Each reported tick is retained, including rotations containing
  multiple ticks.
- Press-to-mute and touch-to-play/pause remain unchanged.

The dial action and its UUID are unchanged. Track navigation is sent through
the existing serialized Spotifast command queue. Physical Stream Deck + testing
is still required; automated SDK tests do not verify the hardware direction.

## Français

La rotation de la molette Stream Deck + peut maintenant être configurée pour
chaque action de molette :

- **Régler le volume** reste le réglage par défaut, y compris pour les molettes
  déjà configurées.
- **Changer de morceau** associe les crans horaires à Suivant et les crans
  antihoraires à Précédent. Chaque cran transmis est conservé, même lorsque la
  rotation en contient plusieurs.
- L’appui pour couper le son et le toucher pour lire/mettre en pause ne changent
  pas.

L’action de molette et son UUID restent inchangés. Le changement de morceau
utilise la file de commandes Spotifast sérialisée. Un test physique sur Stream
Deck + reste nécessaire; les tests SDK automatisés ne vérifient pas le sens
réel de la rotation.
