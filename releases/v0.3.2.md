# Spotifast Stream Deck 0.3.2 — Beta

## English

Version 0.3.2 adds dedicated Multimedia controls for Stream Deck +, a local
visual simulator for contributors, and dependency security fixes.

### Stream Deck + controls

- **Multimedia** is a separate dial action showing artwork, title, artist,
  elapsed and total time, shuffle/playback state, and a progress bar.
- Rotate clockwise for the next track and counter-clockwise for the previous
  track. Press to play or pause. Tap the touch-strip icons for shuffle,
  previous, play/pause, and next.
- **Volume (dial)** keeps its existing role: rotate to adjust volume, press to
  mute, and tap the display to play or pause. Existing volume setups keep their
  action identifiers and settings.

### Local visual simulator

- Test four configurable dials, four touch-strip segments, and eight keys in a
  browser, without owning a Stream Deck +. Mouse drag, wheel, keyboard, and
  touch coordinates go through the real Elgato SDK and plugin runtime.
- Try independent Volume/Multimedia assignments, multiple ticks per event,
  offline playback, long metadata, unknown duration, and an empty player. An
  interaction log shows events and the resulting commands.
- The simulator uses a fictional player and does not launch or control your
  Spotifast installation. It is a development tool included in the source
  repository, separate from the plugin installer. Run `npm ci` followed by
  `npm run simulator`; on Windows, the included **Lancer le simulateur.cmd**
  launcher can also start it. See the
  [simulator guide](https://github.com/NoLife141-Teams/spotifast-streamdeck/blob/v0.3.2/docs/streamdeck-plus-simulator.md).

### Security and maintenance

- Update the Elgato Stream Deck SDK to **3.0.3** and CLI to **1.10.3**.
- Resolve the dependency audit findings by using patched **Zod 4.6.7** for
  Elgato utilities and updating **fast-uri to 3.1.9**.

### Installation, verification, and limits

Download **rocks.spotifast.streamdeck.streamDeckPlugin** from this release and
open it to install or update. Requires **Windows x64**, **Stream Deck 7.1+**,
and Spotifast installed and signed in to Spotify. Existing Spotify account
requirements are unchanged. The plugin remains free and MIT licensed.

The automated checks run **231 tests on each Windows runtime, Node 20 and 22**,
plus dependency audit, build, Elgato validation, packaging, and an SDK smoke test
from the extracted installer. The published installer is the exact verified
Windows Node 20 artifact, without rebuilding. **SHA256SUMS.txt** covers the
installer, **LICENSE**, **RELEASE_NOTES.md**, and **package-verification.json**.

This is a **beta release**. **Physical Stream Deck + behavior has not been
tested for this version.** The simulator approximates screen rendering and
cannot certify hardware touch behavior, dial feel, or real CLI/network timing.

## Français

La version 0.3.2 ajoute des commandes Multimedia dédiées au Stream Deck +, un
simulateur visuel local pour les contributeurs et des correctifs de sécurité
des dépendances.

### Commandes Stream Deck +

- **Multimedia** est une action de molette distincte qui affiche la pochette,
  le titre, l’artiste, le temps écoulé et total, les états de lecture et de
  lecture aléatoire, ainsi qu’une barre de progression.
- Tourner dans le sens horaire pour passer au morceau suivant et dans le sens
  antihoraire pour revenir au précédent. Appuyer pour lire ou mettre en pause.
  Les icônes tactiles commandent la lecture aléatoire, le morceau précédent,
  la lecture/pause et le morceau suivant.
- **Volume (molette)** conserve son rôle : rotation pour régler le volume,
  appui pour la sourdine et toucher pour lire ou mettre en pause. Les molettes
  de volume existantes conservent leurs identifiants d’action et leurs réglages.

### Simulateur visuel local

- Tester quatre molettes configurables, quatre zones tactiles et huit touches
  dans un navigateur, sans posséder de Stream Deck +. Le glissement, la roulette
  de souris, le clavier et les coordonnées tactiles passent par le véritable
  SDK Elgato et le code du plugin.
- Essayer des affectations Volume/Multimedia indépendantes, plusieurs crans par
  événement, le mode hors ligne, des métadonnées longues, une durée inconnue ou
  un lecteur sans morceau. Un journal affiche les événements et leurs commandes.
- Le simulateur utilise un lecteur fictif et ne lance ni ne contrôle ton
  installation Spotifast. Cet outil de développement est fourni dans le dépôt
  source, séparément de l’installateur du plugin. Exécuter `npm ci`, puis
  `npm run simulator` ; sous Windows, le fichier **Lancer le simulateur.cmd**
  permet aussi de le démarrer. Voir le
  [guide du simulateur](https://github.com/NoLife141-Teams/spotifast-streamdeck/blob/v0.3.2/docs/streamdeck-plus-simulator.md).

### Sécurité et maintenance

- Mise à jour du SDK Elgato Stream Deck vers **3.0.3** et de la CLI vers **1.10.3**.
- Correction des alertes de l’audit des dépendances avec **Zod 4.6.7** pour les
  utilitaires Elgato et la mise à jour de **fast-uri vers 3.1.9**.

### Installation, vérifications et limites

Télécharger **rocks.spotifast.streamdeck.streamDeckPlugin** depuis cette release,
puis l’ouvrir pour installer ou mettre à jour. Nécessite **Windows x64**,
**Stream Deck 7.1+** et Spotifast installé et connecté à Spotify. Les exigences
du compte Spotify restent inchangées. Le plugin reste gratuit sous licence MIT.

Les contrôles automatisés exécutent **231 tests sur chacun des runtimes Windows
Node 20 et 22**, ainsi que l’audit des dépendances, la compilation, la validation
Elgato, l’empaquetage et un test SDK depuis l’installateur extrait. L’installateur
publié est l’artefact Windows Node 20 vérifié, sans nouvelle compilation.
**SHA256SUMS.txt** couvre l’installateur, **LICENSE**, **RELEASE_NOTES.md** et
**package-verification.json**.

Cette release est **bêta**. **Le fonctionnement sur un véritable Stream Deck +
n’a pas été testé pour cette version.** Le simulateur approche le rendu de
l’écran et ne certifie ni le comportement tactile physique, ni la sensation
des molettes, ni les délais réels de la CLI et du réseau.
